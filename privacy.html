Jarvis Studio — Privacy Policy

Last updated: 27 September 2026

Jarvis Studio is a personal desktop assistant used only by its owner. This policy explains what happens to TikTok data when the owner connects their TikTok account.

What data the app uses

  • TikTok sign-in tokens (access and refresh tokens) — used only to post videos to the owner's own account.
  • Basic account information (user.info.basic) — used only to confirm which account is connected.
  • Creator posting options returned by TikTok (e.g. available privacy levels) — used only when posting.

Where it is stored

Everything stays on the owner's own computer. Tokens are stored encrypted with the Windows user account's built-in data protection (DPAPI). The app has no servers of its own and does not send TikTok data anywhere except back to TikTok's official API.

Sharing

No data is sold, shared or disclosed to third parties.

Deleting data

Choosing "Disconnect" in the app's settings deletes the stored tokens immediately. Access can also be revoked in TikTok under Settings → Security → Manage app permissions.
